## Access and use

- Internal/agent-only: do not publish or share these files with prospects.
- Raw sources are evidence, not automatically current policy.
- Use the source-priority rule in the repository `README.md`.
- Newer dated written instructions override older general guidance on the same question.
- When the raw source conflicts with the operational KB, do not silently choose; follow the evidence label and record the conflict.
- Do not edit the snapshots to make them "cleaner." Add interpretation to `knowledge/`, `playbooks/`, or `operations/` instead.
